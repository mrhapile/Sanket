# SANKET Submission Checklist

## Required deliverables

- [ ] Clear pain point: degraded voice communication makes instructions hard to recover and verify.
- [ ] India impact note: voice-first use with Hindi, English, and mixed-language workflows; impact is proposed, not measured.
- [ ] Public GitHub repository link with reproducible setup instructions.
- [ ] Three-minute screen recording demonstrating the full required workflow.
- [ ] Short Wispr Flow note: Wispr Flow was used as the primary dictation workflow to place speech-derived text into the focused composer; users review it before sending.

## Repository README must include

- [ ] What SANKET does in one paragraph.
- [ ] Local run instructions.
- [ ] The simulated message lifecycle and network modes.
- [ ] What is tested.
- [ ] Prototype limits: no real radio, defence integration, offline Wispr transcription, or production-security claim.
- [ ] Link or path to the demo recording when available.

## Final honesty check

- [ ] No claim says messages are understood merely because they are delivered.
- [ ] No claim says transcription is exact or safe in all languages/accents.
- [ ] No claim implies authorised military deployment.
- [ ] Every on-screen status matches the lifecycle contract.
